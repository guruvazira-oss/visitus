# Contributing

Thanks for your interest. This is a portfolio/benchmark project; contributions that improve
rigour, documentation or test coverage are welcome.

## Development setup
```bash
uv sync
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

## Ground rules
- **No fabricated results.** Never hand-type agreement numbers; they must be generated by the
  analysis pipeline from committed artifacts. If an experiment or human labels are missing,
  the output must say PENDING.
- **The dataset is frozen.** `data/transcripts.jsonl` is the experimental artifact. Changing
  it means a new `dataset.version` and a `--force` regeneration, not a silent edit.
- **Rubrics are immutable.** Add `rubric_vN.yaml` with a changelog; never edit a released one.
- **Tests must not call a paid API.** Use the `MockProvider` or the heuristic baseline.
- **No secrets.** `.env` is git-ignored; never commit a key.

## Adding a judge provider
Implement `JudgeProvider` in `src/voice_eval/judge/provider.py` and add a branch in
`get_provider`. The scoring pipeline must stay unchanged.
